## 1. 目的

React、TypeScript、および最新のフロントエンド技術スタック（axios、React Query、zod など）を使用して、実践的な備品管理アプリケーションを開発することにより、
API 通信、データキャッシュ管理、バリデーション、状態管理の基本スキルを習得することです。

また、実際の開発現場に必要な「型安全性」や「エラーハンドリング」などのベストプラクティスを身につけることも目的としています。

## 2. 開発環境の準備

```bash
# 依存パッケージのインストール
npm install

# 開発サーバーの起動（フロントエンドのみ）
npm run dev

# モックAPIサーバーの起動（別ターミナルで実行）
npm run api

# 開発サーバーとモックAPIサーバーを同時に起動
npm run dev:all
```

## 学習ガイド

このプロジェクトでは、以下の 5 つのタスクに分けて学習を進めました。各タスクの詳細な実装方法とコード例は、専用のドキュメントファイルにまとめられています。

### Task 1: [Web API の適切な呼び出しと実装方法](./Web-API-の適切な呼び出しと実装方法.md)

axios、React Query、zod を使用した API 通信の実装を行いました。API リクエストの送信、レスポンスのバリデーション、キャッシュ管理、エラーハンドリングの実践的な手法を実装しています。

### Task 2: [フォームの制御と入力検証の実装方法](./フォームの制御と入力検証の実装方法.md)

react-hook-form と zod を組み合わせた効率的なフォーム管理を実装しました。フォームの状態管理、バリデーション、エラーメッセージ表示、送信処理の実装を行っています。

### Task 3: [ページ遷移（ルーティング）の実装方法](./ページ遷移（ルーティング）の実装方法.md)

react-router-dom を使用した SPA のルーティング実装を行いました。基本的なルート定義、動的パラメータの取得、ネストされたレイアウト、プログラムによるナビゲーションを実装しています。

### Task 4: [グローバルステート管理の実装方法](./グローバルステート管理の実装方法.md)

Zustand を使用したシンプルなグローバル状態管理を実装しました。ストアの作成、状態の読み取りと更新、複数ストアの分割、デバッグツールとの連携を行っています。

### Task 5: [テストの実行と検証方法](./テストの実行と検証方法.md)

Vitest と React Testing Library を使用したテスト実装を行いました。コンポーネントテスト、ユーザーイベントのシミュレーション、フォームバリデーションのテスト、非同期処理のモック化を実装しています。
